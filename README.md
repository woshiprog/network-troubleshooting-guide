# 网络故障排查指南

网络出现问题时，先确认影响范围，再检查设备、Wi-Fi、浏览器、DNS、路由器或上游线路。

本站采用“现象 → 范围 → 测试 → 结果 → 下一步”的排查顺序，帮助普通用户减少无效重启、重复修改设置和不必要的网络重置。

访问网站：

https://woshiprog.github.io/network-troubleshooting-guide/

## 从哪里开始

先回答三个问题：

1. 是只有一台设备异常，还是所有设备都异常？
2. 是只有一个网站打不开，还是所有网站和应用都无法连接？
3. 使用网线和 Wi-Fi 时，问题是否相同？

根据结果进入对应指南。

## 操作安全

涉及忘记网络、修改 DNS、网络重置、固件更新或恢复路由器出厂设置时，请先记录原配置并确认恢复方法。

公司、学校和其他受管理的网络应优先联系网络管理员。出现设备进水、焦味、异常高温、外壳损坏或光纤折断时，请停止自行操作，并联系运营商或设备售后。
