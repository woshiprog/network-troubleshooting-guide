# 网络故障排查指南

网络出现问题时，先确认影响范围，再检查设备、Wi-Fi、浏览器、DNS、路由器或上游线路。

本站采用“现象 → 范围 → 测试 → 结果 → 下一步”的排查顺序，帮助普通用户减少无效重启、重复修改设置和不必要的网络重置。

访问网站：

https://woshiprog.github.io/network-troubleshooting-guide/

## 从哪里开始

先回答三个问题：

1. 是只有一台设备异常，还是多台设备同时异常？
2. 是只有一个网站打不开，还是多个网站和应用都无法连接？
3. 使用 Wi-Fi 和网线时，问题是否相同？

根据结果进入对应指南。

## 排查原则

- 先测试，不先修改设置。
- 先确认影响范围，再选择排查方向。
- 一次只修改一个项目。
- 修改前记录原设置和恢复方法。
- 单设备问题不重置整个家庭网络。
- 单网站问题不恢复路由器出厂设置。
- 单次测速或单次超时不作为最终结论。
- 公司、学校和受管网络优先联系管理员。

## 操作安全

涉及忘记网络、修改 DNS、网络重置、固件更新或恢复路由器出厂设置时，应先记录原配置并确认恢复方法。

设备出现异常高温、焦味、冒烟、进水、外壳变形或反复断电时，应立即断开电源并联系售后。

光纤折断、接口损坏或光猫持续显示对应型号说明书定义的线路告警时，应联系运营商，不要自行拆机、清洁或反复插拔光纤接头。

## 内容范围

本站提供家庭网络和个人设备的一般故障排查信息，不替代运营商线路检测、设备维修或专业网络管理。

不同系统版本、路由器型号和运营商网络可能存在差异。涉及具体菜单、指示灯或固件操作时，应以对应厂商针对当前型号提供的说明为准。
